## Vision

### 10x Check
The 10x version of Movie Night isn't just "better recommendations." It's an app that knows your relationship's taste better than you do. After 10 sessions, it can predict tension points before you set them. After 20, it recommends movies you didn't know existed that feel specifically picked for the two of you. The taste map becomes a living document of your shared cultural identity. And the UX makes the ritual itself feel like an event, not a search.

## Additional Review Findings (no decision needed)

- POC used as functional spec only, not visual starting point. Build UI from scratch with frontend-design skill.
- Full CF Workers observability stack: Workers Logs + Automatic Tracing + Logpush to Grafana Cloud. Structured JSON logging on every matching call.
- Group-membership auth check on all profile routes.
- Output sanitization on all Claude response text (no raw HTML rendering).
- OG images cached in KV. WAF rules to block crawlers on authenticated endpoints.
- Invite codes: cryptographic UUIDs, rate-limited, minimal info on join page (group name only, no PII).
- Recommendations table gets `model`, `prompt_version`, `candidate_snapshot` fields for reproducibility.
- Account deletion anonymizes shared records rather than cascade-deleting group history.
