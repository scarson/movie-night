## Affected Pages/Routes
- `/` (landing page) — unauthenticated product explanation page
- `/api/auth/google` — OAuth initiation, verify redirect to Google
- `/api/auth/google/callback` — OAuth callback, verify session cookie creation
- `/api/auth/me` — returns current user, verify auth check
- `/api/user/profile` — GET/PUT profile CRUD, verify auth + validation
- `/api/groups` — POST create group, verify invite code generation
- `/api/groups/join` — POST join via invite code, verify code validation + rate limit
- `/api/groups/[id]` — GET group details, verify member-only access
- `/api/sessions` — POST create session, verify group membership
- `/api/sessions/[id]/match` — POST trigger matching, verify rate limit + Claude call
- `/api/sessions/[id]/refine` — POST refinement round, verify kept/removed/feedback
- `/api/titles/search` — GET TMDB search, verify query sanitization
- Profile setup screen — form validation, comfort movie search, tag selection
- Mood screen — tag selection, freetext, discover-new toggle
- Results screen — taste map, ranked list, conversational tabs

## Key Interactions to Verify
- Complete quick-match flow: open app → select group → mood tags → match → results
- Complete full-ritual flow: edit profiles → mood → match → results → refine → regenerate
- Group invite: create group → share code → second user joins
- Refinement loop: keep/remove movies → optional feedback → regenerate (up to 10 rounds)
- Rough-day toggle: private, affects weighting, invisible to partner
- Tab switching between Taste Map / Ranked List / Conversational results
- Solo mode: single user, no group, solo-specific prompt

## Edge Cases
- Invalid/expired invite code on group join
- Max refinement rounds (10) reached — show appropriate message
- Claude API timeout — "movie brain is taking a nap" + retry
- Claude returns malformed JSON — retry once, then graceful error
- All recommendations removed (all ✕'d) — fresh slate regeneration
- Empty mood (no tags, no freetext) — "surprise us" mode
- Session expired mid-flow — redirect to login
- User in multiple groups — group selection screen
- TMDB search returns no results — appropriate empty state
- Stale streaming data (>14 days) — show "as of [date]" badge

## Critical Paths
- OAuth round-trip: Google redirect → callback → session cookie → authenticated state
- Matching pipeline: profiles + mood → prompt construction → Claude API → JSON parse → render
- Prompt construction: verify all profile data, mood, rough-day weighting appear correctly
- Response parsing: taste map extraction, recommendation list, sanitized conversational text
- Rate limiting: 10 rounds per session enforced, monthly cap checked
- XSS prevention: all Claude-generated text sanitized before rendering
