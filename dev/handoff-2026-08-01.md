## The one thing to carry forward

**A class of plan defect survives adversarial plan review and is caught only by an implementer who
runs the test, or a reviewer who checks reality against the code.** This happened in *every single
group*:

- **Prescribed tests that cannot fail before the fix.** G2, G3, G4, G5, G6 and G1 each found at
  least one. G1's was the worst: the plan's prescribed loser test cannot distinguish the correct fix
  from the exact `rotated_at`-reuse bug the plan itself boxes as "the highest-risk line in the task."
- **Inverted technical justification.** The plan mandated `crossOrigin=""` on the TMDB preconnect
  "because posters are anonymous-CORS". They are no-CORS — proven in a browser (same URL: plain
  `<img>` loads at naturalWidth 342, `crossorigin="anonymous"` fails at 0). The mandated attribute
  would have warmed a socket pool the LCP image can never use.
- **Rationale resting on an unchecked UI default.** "Make pick #1 eager, it's the LCP element" — the
  results page defaults to the taste-map tab, so no poster is in the DOM at first paint at all.
- **Citing a source that says the opposite.** Migration `0004` cited the perf audit as authority for
  dropping an index the audit explicitly said to keep.

In each case **the code was fine and the justification was wrong** — which is the failure mode that
ossifies in a comment and outlives everyone who could have questioned it. Budget for implementer
pushback; instruct subagents to report plan defects rather than silently complying *or* silently
"fixing".

## Operational guardrails

Everything in `dev/handoff-2026-07-28.md` §Operational guardrails still holds — jsdom has no layout
or CSS cascade, Tailwind resolves conflicts by stylesheet order, composite alpha before comparing
contrast, `:focus` needs OS window focus, `next dev` has no Cloudflare bindings. Added this session:

- **`dev/implementation-log.md` merges with `union`** (`.gitattributes`). Parallel branches all append
  to it; before this, every rebase conflicted. Do not "fix" the union setting.
- **zsh arrays are 1-indexed.** A `sed` built from `${M[0]}` expanded to a bare `d` and deleted every
  line of the implementation log mid-rebase. Recovered with `git checkout --merge`. Never build a
  destructive command from an unvalidated array index.
- **PREP's failure-injection helper fails silently in three ways.** A typo in `match`, an `onCall`
  overshoot, or building the wrapper after the route's db mock all yield a test that passes against
  the code it was written to catch — and the natural assertions are true on the happy path too.
  **Assert `injectedFailureCount(db)` in every interrupted-success test.**
- **The synchronous fake D1 cannot prove concurrency.** Several groups wanted to; none did. Say what
  a test proves and what it cannot rather than writing a `Promise.all` costume.
- **GitHub sometimes does not fire CI on a push**, and close/reopen does not force it. A rebase that
  produces new commits does. Never merge on local gates alone without saying so.
- **Do not check the same branch out in two worktrees.** It moves a reviewing agent's HEAD mid-pass.
